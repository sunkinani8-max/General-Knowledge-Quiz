# 🧠 General Knowledge Quiz

## 📌 Project Overview

The **General Knowledge Quiz** is a simple Python-based quiz program that asks users three general-knowledge questions, checks their answers, and displays their final score.

This project demonstrates basic Python programming concepts such as user input, variables, conditional statements, string handling, and formatted output.

## 🎯 Project Objectives

- Ask the user three general-knowledge questions.
- Check whether each answer is correct.
- Award one point for every correct answer.
- Display the final score out of 3.
- Practice Python fundamentals and decision-making.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Editor:** Visual Studio Code
- **Version Control:** Git and GitHub

## ❓ Quiz Questions

1. What is the capital of France?
2. How many days are there in a week?
3. Which planet is known as the Red Planet?

## 💡 Python Concepts Used

- `input()` for accepting user answers.
- Variables for storing answers and scores.
- `if-else` statements for checking answers.
- `==` for string comparison.
- `.strip()` for removing extra spaces.
- `.lower()` for case-insensitive comparison.
- `score = 0` for initializing the score.
- `score += 1` for increasing the score.
- F-strings for displaying the final result.

## ▶️ How to Run the Project

**Step 1:** Install Python 3 on your computer.

**Step 2:** Clone this repository:

```bash
git clone https://github.com/YOUR_USERNAME/General-Knowledge-Quiz.git
```

**Step 3:** Open the project folder:

```bash
cd General-Knowledge-Quiz
```

**Step 4:** Run the Python program:

```bash
python3 general_knowledge_quiz.py
```

**Step 5:** Answer all three questions and view your final score.
